# Food-Price-Analysis-In-Nigeria
## Project Objective 
This project explores commodity prices across Nigerian markets, uncovering price trends and variation across different states. 

 ## Process 
- Data Processing & Cleaning: Used Power Query to transform, clean, and prepare the raw dataset for analysis, including handling inconsistencies and ensuring the data was structured correctly.
- KPI Measure Creation : Used DAX to create calculated measures and key performance indicators (KPIs) that helped measure and evaluate the most important aspects of the data.
- Analysis & Visualization: Used Power BI to analyze the processed data and build interactive dashboards that highlighted trends, patterns, and key insights.

 - ## KPIs
 - Total Commodities
 - Total Markets
 - Total States
 - Total Price In Naira
 - Total Price In Dollar
 - Average Price In Naira
 - Average Price In Dollar
